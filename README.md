### 짧은 확인 방법 4줄 (T03-C31)

```text
① 어디로 가나요: 브라우저에서 무로그인 편집기 메인 캔버스(ToonsCard Studio)로 접속합니다.
② 3단계 이내 행동: [이미지 업로드(PNG/JPEG)] → [문구 입력 및 위치/크기/색상 조절] → [PNG 다운로드] 버튼을 클릭합니다.
③ 무엇이 보이면 통과인가요: 실시간 미리보기 캔버스와 다운로드된 PNG 파일의 문구 위치·줄바꿈·이미지 배치가 100% 일치합니다.
④ 안 될 때 무엇이 보이나요: 지원하지 않는 파일(.gif 등) 또는 문법 손상 JSON 업로드 시 기존 작업을 보존하며 빨간색 거부 사유 배너가 즉각 표시됩니다.
```

### AI와 나의 판단 3줄 (T03-C32)

```text
① AI에게 맡긴 일: 1:1·4:5·9:16 다중 화면비의 Canvas 2D 렌더링 수학 공식 설계, 극단 입력 12건의 테스트베드 스캐폴딩 및 Prettier/Oxlint 자동화 검증 지원.
② 학생이 직접 판단한 일: 공백 없는 초장문 영문 텍스트의 Canvas 우측 이탈 결함을 해결하기 위해 grapheme 기반의 지능형 break-word 줄바꿈 알고리즘을 채택하고, 로컬스토리지 안정 ID(UUID) 기반의 자가 치유 CRUD 아키텍처를 결정함.

```

## 🏗️ 3. 5대 카드별 핵심 구현 명세

### 🖼️ 카드 1 — 편집과 미리보기 (T03-C01 ~ T03-C10)

- **무로그인 공개 웹 (T03-C01)**: 인증, 계정 생성, 비밀번호, OAuth, CAPTCHA 없이 시크릿 창에서 즉시 시작 가능.
- **첫 화면 노출 (T03-C03)**: 1366×768 및 1920×1080 해상도에서 이미지 도구와 문구 도구가 스크롤 없이 첫 화면에 100% 보임.
- **파일 포맷 지원 (T03-C04, T03-C05)**: PNG(알파 채널 투명 포함) 및 JPEG 이미지 업로드 및 합성 완벽 지원.
- **실시간 조작 반영 (T03-C06, T03-C07, T03-C08)**: 문구 위치(상/중/하/Y오프셋), 문구 크기(16~120px), 문구 색상(텍스트, 외곽선, 하이라이트 배지 박스, 그림자)이 캔버스에 즉각 반영.
- **미지원 파일 방어 (T03-C09, T03-C10)**: `.gif`, `.pdf`, `.txt` 등 미지원 파일 주입 시 기존 작업 내용이 100% 안전하게 유지되며 명확한 거부 사유 배너 노출.

### 📐 카드 2 — 화면과 파일의 일치 (T03-C11 ~ T03-C13)

- **세 화면비 지원**:
  - `1:1 정사각형` (1080 × 1080 px): 인스타그램 피드, 커뮤니티 밈 최적화
  - `4:5 세로 피드` (1080 × 1350 px): 카드뉴스, 인스타 세로 게시물
  - `9:16 숏폼/스토리` (1080 × 1920 px): 유튜브 쇼츠, 인스타 릴스, 틱톡 세로 썸네일
- **화면/파일 일치성**: 상대 좌표계(0~100%) 및 Canvas 2D 래핑 엔진을 공유하여 미리보기 화면과 다운로드된 고해상도 이미지 간 텍스트 줄바꿈·좌표 왜곡이 0% 발생.
- **화면비 일치 대조 모달**: 화면 미리보기와 내려받은 파일 이미지를 나란히 비교 검사하는 전용 모달 제공.

### ⚡ 카드 3 — 극단 입력 12건 & 대표 결함 전후 (T03-C14 ~ T03-C16)

- **12건 극단 입력 전수 검사 (T03-C14)**:
  1. 공백 없는 초장문 한글 (70자 연속)
  2. 공백 없는 초장문 영문/숫자 (대표 결함)
  3. 연속 다중 줄바꿈 (연속 빈 줄 5회)
  4. 복합 이모지 및 특수기호 혼합 (👨‍👩‍👧‍👦, 🔥, 🚀 등)
  5. 공백 문자열 및 빈 텍스트 방어
  6. 초고해상도 울트라와이드 이미지 (3840×1080)
  7. 초고해상도 익스트림 롱 세로 이미지 (1080×3840)
  8. 투명 알파 채널 PNG 이미지 합성
  9. 1×1 픽셀 극소형 이미지 로드
  10. HTML/스크립트 XSS 인젝션 방어 (`<script>` 태그 리터럴 렌더링)
  11. RTL 아랍어 및 특수 기호 혼합
  12. 극단적 폰트 크기 경계값 (120px 초대형)
- **대표 결함 수정 전후 (T03-C15)**:
  - **수정 전 (FAIL)**: 공백 기준 단순 split 분할 시, 단어 자체가 너비를 초과하여 캔버스 우측으로 텍스트가 잘려나가는 버그 발생.
  - **수정 후 (PASS)**: Grapheme 단위 누적 너비 계산을 적용하여 단어 내부라도 가로 한계 너비 도달 즉시 지능적으로 개행(break-word) 처리하여 100% 안전 렌더링.
- **작업 보존 시험 (T03-C16)**: 잘못된 극단 입력 시도 후에도 기존 편집본이 보존됨을 확인하는 자동 시험기 내장.

### 📁 카드 4 — 실제 템플릿 관리 CRUD (T03-C17 ~ T03-C21)

- **3개 이상 생성 지원 (T03-C17)**: 기본 제공 사전 템플릿 외에 사용자가 직접 3개 이상의 신규 템플릿을 무제한 등록(Create) 가능.
- **안정된 ID 체계**: 배열 인덱스 대신 고유 불변 ID(`tpl_timestamp_hash`)를 부여하여 순서 변경이나 삭제 시에도 데이터 오작동 원천 방지.
- **불러오기(R), 수정(U), 삭제(D)**: 템플릿 이름 수정 및 현재 캔버스 상태 로드/삭제 완벽 지원.
- **새로고침 유지 (T03-C21)**: `localStorage` 영구 보존 및 파싱 에러 시 기본값 복원 자가 치유(Self-healing) 탑재.

### 🛡️ 카드 5 — 옮겨 쓰기와 완성본 & 보안 규격 (T03-C22 ~ T03-C32)

- **JSON 3종 시험기 (T03-C22 ~ T03-C24)**:
  - `정상 JSON`: 템플릿 목록에 추가되고 캔버스에 즉시 복원.
  - `문법 손상 JSON`: SyntaxError 감지 후 저장 전 즉시 거부, 기존 목록 보존.
  - `필수 누락 JSON`: 스키마(aspectRatio, textLayers 등) 누락 감지 후 저장 전 즉시 거부, 기존 목록 보존.
- **3대 완성 이미지 쇼케이스 (T03-C25 ~ T03-C27)**:
  - 작품 1 (1:1): 개발자의 월요일 vs 금요일 (본인 직접 창작, CC-BY-4.0)
  - 작품 2 (4:5): 2026 개발자 모티베이션 (본인 직접 기획/제작)
  - 작품 3 (9:16): AI 풀스택 엔지니어링 3원칙 (수업 제공 규격 & Unsplash 무료 라이선스 합성)
- **공개 안전 전수 감사**:
  - 위치 정보 메타데이터 0건 (T03-C28): Canvas toBlob 추출로 EXIF/GPS 태그 100% 자동 스트립.
  - 개인정보 노출 0건 (T03-C29): 주민번호, 휴대폰, 집주소 등 법적 PII 0건.
  - 비밀값 원문 노출 0건 (T03-C30): API Key, Access Token 등 비밀값 0건.

## 🛠️ 4. 기술 스택 및 품질 자동화

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide React
- **Rendering Engine**: HTML5 Canvas 2D API (자체 지능형 break-word 래핑 엔진)
- **Code Quality**: Prettier, Oxlint, Vite 8

```bash
# 1. Prettier 코드 스타일 검사
npm run format:check

# 2. Oxlint 정적 분석 검사 (경고 및 에러 0건)
npm run lint

# 3. TypeScript 컴파일 & Vite 프로덕션 빌드 (0 오류)
npm run build
```
