### 📋 짧은 확인 방법 4줄 (T03-C31)

```text
① 어디로 가나요: 브라우저에서 무로그인 편집기 메인 캔버스(ToonsCard Studio)로 접속합니다.
② 3단계 이내 행동: [이미지 업로드(PNG/JPEG)] → [문구 입력 및 위치/크기/색상 조절] → [PNG 다운로드] 버튼을 클릭합니다.
③ 무엇이 보이면 통과인가요: 실시간 미리보기 캔버스와 다운로드된 PNG 파일의 문구 위치·줄바꿈·이미지 배치가 100% 일치합니다.
④ 안 될 때 무엇이 보이나요: 지원하지 않는 파일(.gif 등) 또는 문법 손상 JSON 업로드 시 기존 작업을 보존하며 빨간색 거부 사유 배너가 즉각 표시됩니다.
```

## 🚀 3. 핵심 사용자 경험 및 아키텍처 고도화

### 🎯 1) 캔버스 마우스 직접 인터랙션 (Direct Manipulation)

- **자유 드래그 이동**: 캔버스 위의 문구를 마우스나 터치로 직접 클릭하여 원하는 위치 어디로든 자유롭게 이동할 수 있습니다 (`posX`, `posY` 실시간 연동).
- **4코너 리사이즈 핸들**: 선택된 문구 박스 외곽의 4개 코너 핸들을 드래그하여 글자 크기(16px ~ 120px)를 직관적으로 조절할 수 있습니다.
- **Pointer Capture 기술**: 캔버스 영역 바깥으로 마우스 커서가 빠르게 벗어나더라도 포인터 캡처(`setPointerCapture`)를 통해 끊김 없이 드래그가 유지됩니다.

### ✏️ 2) 캔버스 요소 더블클릭 문구 수정 (Inline Text Editing)

- **인라인 편집 카드 즉시 호출**: 캔버스 위 문구 요소를 마우스 더블클릭하거나 모바일 터치 더블탭(350ms 감지)하면 해당 위치에 인라인 텍스트 편집기가 즉시 팝업됩니다.
- **실시간 무깜빡임 동기화**: 인라인 편집기에서 텍스트를 입력하면 오프스크린 더블 버퍼링 엔진과 즉시 연동되어 캔버스 텍스트가 실시간으로 변경됩니다.
- **다양한 편집 단축키**: `Enter`(줄바꿈), `Ctrl/Cmd + Enter` 또는 `Esc`(편집 완료), 빈 캔버스 클릭 시 자동 완료를 지원합니다.
- **좌측 패널 탭 연동**: 좌측 패널의 레이어 탭을 더블클릭해도 텍스트 입력창으로 즉시 포커스되며 텍스트가 전체 선택됩니다.

### ⚡ 3) 깜빡임 없는 무결점 렌더링 (Zero-Flicker Architecture)

- **오프스크린 캔버스 더블 버퍼링**: 백그라운드 오프스크린 캔버스에 이미지와 텍스트를 모두 그린 후 최종 완성본을 화면 캔버스에 단 한 번의 프레임(`drawImage`)으로 복사하여 텍스트 입력 중 화면 깜빡임을 100% 제거했습니다.
- **인메모리 이미지/폰트 캐시**: 업로드된 이미지 및 폰트 로드 상태를 메모리에 캐싱하여 타이핑 시 비동기 딜레이 없는 즉각적인 실시간 렌더링을 구현했습니다.
- **디바운스 스토리지 저장 (300ms)**: 빠른 텍스트 입력 중 메인 스레드가 블로킹되지 않도록 스토리지를 디바운스 처리하고, 브라우저 이탈 시(`beforeunload`) 즉시 플러시하여 데이터 유실을 방지합니다.

### 🎚️ 4) 배경 이미지 및 텍스트 레이어 투명도 제어 (Opacity Controls)

- **배경 투명도 (0% ~ 100%)**: 배경 이미지의 투명도를 슬라이더 및 원클릭 프리셋(25%, 50%, 75%, 100%)으로 자유롭게 설정하여 텍스트 가독성을 극대화합니다.
- **문구 레이어 투명도 (10% ~ 100%)**: 각 문구 레이어별 독립적인 알파 채널을 설정하여 워터마크나 은은한 보조 문구를 디자인할 수 있습니다.

### 🎨 5) 제로 블러(Zero-Blur) 고성능 모노크롬 디자인 시스템

- **불필요한 GPU 오버헤드 원천 제거**: CSS `backdrop-blur` 연산을 배제하고 고대비 미세 보더 및 글래스모피즘 스타일을 구현하여 저사양 데스크톱 및 모바일 기기에서도 일관된 60fps 부드러움을 보장합니다.

> 상대 좌표계(0~100%)와 공용 Canvas 2D 렌더링 파이프라인을 사용하여 화면 캔버스와 다운로드된 고해상도 파일 간의 줄바꿈·문구 위치 왜곡률 0%를 보장합니다.

### ⚡ 카드 3: 극단 입력 12건 & 대표 결함 수정 규격 (T03-C14 ~ T03-C16)

- **12건 극단 입력 전수 검사 (T03-C14)**:
  1. 공백 없는 초장문 한글 (70자 연속)
  2. 공백 없는 초장문 영문/숫자 (대표 결함)
  3. 연속 다중 줄바꿈 (연속 빈 줄 5회)
  4. 복합 이모지 및 특수기호 혼합 (👨‍👩‍👧‍👦, 🔥, 🚀 등)
  5. 공백 문자열 및 빈 텍스트 방어
  6. 초고해상도 울트라와이드 이미지 (3840×1080)
  7. 초고해상도 익스트림 롱 세로 이미지 (1080×3840)
  8. 투명 알파 채널 PNG 이미지 합성
  9. 1×1 픽셀 극소형 이미지 로드
  10. HTML/스크립트 XSS 인젝션 방어 (`<script>` 리터럴 출력)
  11. RTL 아랍어 및 다국어 특수 기호
  12. 극단적 폰트 크기 경계값 (120px 초대형)
- **대표 결함 수정 전후 대조 (T03-C15)**:
  - **수정 전 (FAIL)**: 공백 단위 split 분할로 인해 긴 단어가 캔버스 우측 밖으로 잘려나가는 결함 발생.
  - **수정 후 (PASS)**: Grapheme 단위 누적 줄바꿈(break-word) 알고리즘으로 단어 도중이라도 경계선에서 즉시 개행 처리하여 완벽 렌더링.
- **작업 보존 검증 (T03-C16)**: 극단 케이스 주입 및 실패 상황에서도 기존 편집 템플릿이 보존되는 불변 상태 가드 검증.

### 📁 카드 4: 실제 템플릿 관리 CRUD 규격 (T03-C17 ~ T03-C21)

- **3개 이상 생성 (T03-C17)**: 사용자가 신규 템플릿을 3개 이상 자유롭게 추가(Create).
- **불러오기 (T03-C18)**: 저장된 템플릿 카드를 클릭하여 캔버스에 즉각 복원(Read).
- **수정 (T03-C19)**: 고유 불변 ID를 기반으로 템플릿 이름 및 설정을 안전하게 수정(Update).
- **삭제 (T03-C20)**: 불필요한 템플릿을 개별 삭제(Delete).
- **새로고침 유지 (T03-C21)**: `localStorage` 영구 보존 및 잘못된 데이터 진입 시 자가 치유(Self-healing) 복구.
